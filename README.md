# Cable Team Management System

A web-based management application designed to streamline cable team operations through product management, inventory tracking and AI-assisted business automation.

## Overview

The Cable Team Management System provides a centralized platform for managing products, monitoring inventory and supporting day-to-day business operations. It combines traditional management functionality with AI-powered assistance to improve operational efficiency.

## Key Features

- **Product Catalogue:** Manage and organize products.
- **Inventory Management:** Track stock and inventory information.
- **AI Chat Assistant:** Provides an interactive interface for AI-assisted support.
- **Business Automation:** Supports more efficient management of operational information.
- **Web-Based Interface:** Access management functionality through a centralized application.

## Technology Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- AI integration

## Project Objective

To develop a practical management solution that simplifies product and inventory management while demonstrating how AI can be integrated into business applications.
